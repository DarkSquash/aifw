## Inventário visível no Pi na auditoria

Este é um snapshot do ambiente em 2026-08-23, não uma lista de dependências obrigatórias do AIFW. Packages podem fornecer mais de uma skill, prompt ou extensão. Autoridade, policies e decisões continuam versionadas no projeto; a presença de uma skill nunca concede autoridade adicional ao agente.

### Extensões

`@narumitw/pi-plan-mode:dist`, `@tmustier/pi-usage-extension`, `aifw.ts`, `context-mode:build/adapters/pi/extension.js`, `dirty-repo-guard.ts`, `git-checkpoint.ts`, `permission-gate.ts`, `pi-mcp-adapter`, `pi-subagents` e `protected-paths.ts`.

As capacidades se complementam: `pi-subagents` executa delegação; `aifw.ts` aplica roteamento e governança; `handoff` e o handoff Codex do AIFW preservam contexto para escalada manual; `context-mode` e a família `ctx-*` apoiam continuidade e compactação. Skills de Supabase só devem ser acionadas quando o projeto realmente usa Supabase.
